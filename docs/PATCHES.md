# Patches tab

The **Patches** tab is an optional app-first search for community patch sources.
It helps you find a source that already supports the app you want to patch, then
hands the source to Morphe for confirmation.

## How it works

1. Type an app name or package name. Common abbreviations such as `yt` work,
   and the search ignores spaces and punctuation.
2. Pick an app to expand its sources inline. App icons and source avatars are
   loaded from the upstream index when available; a gradient monogram is used as
   the fallback.
3. When the search is empty, **Installed with patch sources**, **Popular apps**,
   and **Recent** provide quick starting points.
4. Review each source's official/community status, patch count, last update,
   stars, and description.
5. Tap a patch count to see patch names and target versions for that app.
6. Use **Sort** for recommended order, name, last update, or most patches.
   Turn on **Official only** to hide community sources.
7. Use the source menu to view its repository, copy the add-source link, or
   report a problem.
8. Tap **Add** and confirm. The helper re-checks the catalog, then opens Morphe's
   add-source screen scoped to that app.

The helper does not add the source silently. Morphe still shows its own
add-source confirmation, and you can cancel there.

## Data source

The catalog comes from [Awesome Morphe](https://github.com/nvbangg/awesome-morphe),
maintained by nvbangg. The helper builds its own compact index from the upstream
`bundles.json` in the Awesome Morphe GitHub repository; it does not use the
Awesome Morphe website domain.

- Generated by `scripts/build_patch_index.py`.
- Refreshed hourly by `.github/workflows/patch-index.yml`.
- Published at `docs/data/patch-sources.json` and
  `docs/data/patch-details.json` in this repository.
- Fetched with an ETag when the Patches tab opens. Patch names and versions are
  fetched only when you tap a patch count.
- Re-checked against the network before every Add.

Patch sources are third-party projects. They are not reviewed or endorsed by
this helper. Check the source in Morphe and trust it before patching.

## Offline behavior

There is no bundled offline catalog. The last successful download is cached so
the tab opens quickly, but adding a source always requires a successful network
check. If the catalog is more than 30 days old, Add is blocked until a refresh
succeeds.

Your search terms stay on the device; only the catalog files are downloaded.
App icons and source avatars are fetched from the URLs already present in the
upstream index. No query or package name is sent to GitHub, Awesome Morphe, or
the icon hosts.

## Limitations

- Private or self-hosted patch repositories are not in the Awesome Morphe index.
  Add those through Morphe's normal add-source screen or Settings → Sources.
- The Patches tab is discovery only. Source order, enable/disable, and the
  download path are still controlled on the Sources tab and in Settings.
